# 中国跳棋 🎯

基于 Flutter + Flame 的中国跳棋，支持 Android、Windows 与 Web。经典 121 孔六角星棋盘，支持 2 / 3 / 4 / 6 人对局，内置三档电脑对手、连跳提示、悔棋、对局复盘与生涯统计。

## 功能

- ⭐ 经典六角星棋盘：121 个孔位，六个 10 孔营地，正对面营地即目标
- 🎯 完整走子规则：单步走到相邻空孔，连跳可跨过任意一方棋子并连续多跳，中途可停
- 🤖 人机对战：入门 / 普通 / 高手三档，电脑自动接管其余座位，可自由选择自己的座位
- 🧠 高手棋力：三层搜索配合收官计划，优先补满营地尖端，会封堵对手一步进营
- 👥 同屏对战：2 / 3 / 4 / 6 人轮流落子，适合面对面手谈
- 💡 提示：一键给出推荐走法，金色折线标注完整连跳路径，6 秒后自动收起
- ↩️ 悔棋与重开：人机模式一次回到自己上一次走棋之前
- 🎞️ 对局复盘：终局后逐手回看、拖动进度、跳转开局 / 终局与自动播放，棋谱标注每手进营数
- 🏅 最佳着法：复盘自动标出本局亮点（进营优先、其次连跳），棋谱顶部与行内均可一键跳转
- 📈 对局统计：完成对局自动记录胜负、步数、用时与连跳，首页汇总人机胜率、平均步数、最快获胜、常用开局与入营效率
- 🏁 进营进度：每位玩家的实时进度条与 0/10 计数，终局弹窗展示步数、用时、最长连跳与入营效率
- ✨ Flame 棋盘：立体星形底板、木纹孔位、高光棋子、跳跃弧线与落点高亮
- 🎬 动画队列：连续落子按顺序播放，长连跳不会被电脑回棋截断
- 🔄 视角自适应：人机对战把自己的营地转到下方，前进方向朝上
- 🎨 三套棋盘配色：竹影、暖木、夜墨，深浅色主题同步切换
- 🔔 音效与震动：运行时合成选子 / 单步 / 连跳 / 终局音效，仓库不携带音频文件
- 🎵 背景音乐：运行时合成的五声音阶循环，可独立关闭，后台自动暂停
- 🈶 Web 字体：使用 soup_fonts 思源黑体，仓库不存放字体文件
- 📱 响应式布局：手机 / 折叠屏 / 平板 / Windows 窗口自适应
- 🌓 深色模式、简体中文界面、Windows 优先使用 Microsoft YaHei UI
- 🧾 日志按天写入用户目录，设置页可直接查看最近日志

## 规则

1. 每位玩家有 10 枚棋子，起始时填满自己的营地。
2. 目标：把自己的 10 枚棋子全部走进正对面的营地，先完成者获胜。
3. 单步：走到任意相邻的空孔。
4. 连跳：跨过一枚相邻棋子，落到同方向的空孔；可以连续跳多步，中途可随时停下。
5. 可跨过任意一方的棋子，被跨过的棋子不会被吃掉。
6. 连续 120 步没有棋子进营时判和，避免无休止对局。

## 开发

```bash
flutter pub get
flutter analyze
flutter test
```

构建产物由 CI 生成：在 Gitea Actions / GitHub Actions 里手动运行 `build` 工作流，选中 `v*` Tag 时按该 Tag 的版本构建 Android / Windows / Web 并发布 Release，运行 `main` 则产出预览产物。音频在运行时合成、Web 字体来自 soup_fonts，仓库不存放字体与音频文件，本地无需安装 Android SDK 等大型工具链。

## 日志位置

- Windows：`文档/FlutterTiaoqi/logs/app_yyyyMMdd.log`
- Android：应用外部存储目录下的 `FlutterTiaoqi/logs/`
- Web：仅保留内存日志，可在设置页查看

## 目录结构

```
lib/
├── game/       棋盘几何、规则、对局控制器与电脑对手
├── flame/      Flame 棋盘组件与游戏入口
├── pages/      首页、对局页、设置页及通用组件
├── services/   日志、偏好存储、文件系统、音效与音乐合成
├── providers/  设置状态
├── models/     对局设置与结果模型
├── theme/      主题、棋盘配色与玩家配色
└── utils/      常量、格式化、窗口初始化
```
